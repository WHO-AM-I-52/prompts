# 📁 prompts

Коллекция системных промтов для работы с нейросетями.

> **Для ИИ**: При загрузке этого файла — прочитай раздел «Доступные промты» ниже и предложи пользователю выбрать нужный, кратко описав каждый вариант. После выбора загрузи соответствующий файл и работай строго по его инструкциям.


## 📋 Доступные промты

### 1. SONAR DEV 1.0
**Файл**: [sonar_dev.md](sonar_dev.md)  
**Токены**: ~2,800  
**Платформа**: Perplexity Space с GitHub MCP коннектором

**Для чего**: Специализированный промт для разработки **WHO-AM-I-52/SONAR**. Подходит когда нужно:
- Работать с кодом SONAR через GitHub MCP (чтение, коммиты, issues)
- Знать структуру, стиль кода и текущие issues без повторных объяснений
- Соблюдать рабочий процесс: `feature/*` → `dev` → `main`
- Не предлагать изменение архитектуры (без запроса)

**Требует**: GitHub MCP коннектор в Space.

---

### 2. CRITICAL ADVISOR 1.0.1 STANDARD
**Файл**: [critical_advisor_1.0.1_STANDARD.md](critical_advisor_1.0.1_STANDARD.md)  
**Токены**: ~6,420  
**Платформы**: Perplexity, Claude, Gemini, ChatGPT (контекст ≥ 8k)

**Для чего**: Глубокий и аналитический режим работы. Подходит когда нужно:
- Оценить решение, найти ошибки в коде или логике
- Провести критический анализ с проверкой предубеждений
- Разобрать сложную задачу честно и без «утешений»
- Задачи с высокой ставкой (важные решения, архитектура проекта)

**Режимы внутри**: Информационный / Аналитический / Глубокий анализ — выбирается автоматически по типу вопроса.

---

### 3. CRITICAL ADVISOR 1.0.1 LITE
**Файл**: [critical_advisor_1.0.1_LITE.md](critical_advisor_1.0.1_LITE.md)  
**Токены**: ~1,480  
**Платформы**: Все, включая Ollama и модели с малым контекстом (< 8k)

**Для чего**: Облегчённая версия того же протокола. Подходит когда нужно:
- Быстро получить ответ с уровнем доверия
- Работать в ограниченном контексте
- Использовать на слабых или локальных моделях

**Отличие от STANDARD**: Нет расширенной проверки ошибок (M1/M2), нет альтернативных взглядов (M3). Ядро протокола сохранено.

## 🚀 Как использовать

### Через Perplexity Space (рекомендуется)

В начале треда напиши:
> *"Загрузи репозиторий https://github.com/WHO-AM-I-52/prompts, прочитай README и предложи выбрать промт"*

### Вручную

1. Выбери версию по задаче (см. таблицу ниже)
2. Попроси ИИ загрузить конкретный файл из репозитория
3. Работай

## 🔀 Быстрый выбор

| Задача | Промт |
|--------|-------|
| Разработка SONAR, работа с GitHub | **SONAR DEV** |
| Оценить архитектуру, найти ошибки | **STANDARD** |

## 💡 Предложить новый промт

Есть идея для нового промта? Создай **[Issue](https://github.com/WHO-AM-I-52/prompts/issues/new)** с тегом `new prompt` и опиши:

- **Название**: как называется
- **Для чего**: какие задачи решает
- **Платформы**: где тестировался
- **Текст промта**: целиком или частью (если есть)

После обсуждения лучшие предложения попадут в репозиторий как отдельный файл.
