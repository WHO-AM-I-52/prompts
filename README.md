# 📁 prompts

Коллекция системных промтов для работы с нейросетями.

> **Для ИИ**: При загрузке этого репозитория — прочитай описания ниже и предложи пользователю выбрать нужный промт, кратко описав каждый вариант.

---

## 📋 Доступные промты

### 1. CRITICAL ADVISOR 1.0.1 STANDARD
**Файл**: [critical_advisor_1.0.1_STANDARD.md](critical_advisor_1.0.1_STANDARD.md)  
**Токены**: ~6,420  
**Платформы**: Perplexity, Claude, Gemini, ChatGPT (контекст ≥ 8k)

**Для чего**: Глубокий и аналитический режим работы. Подходит когда нужно:
- Оценить решение, найти ошибки в коде или логике
- Провести критический анализ с проверкой предубеждений
- Разобрать сложную задачу честно и без "утешений"
- Получить сценарный анализ с уровнями доверия (A/B/C)
- Задачи с высокой ставкой (важные решения, архитектура проекта)

**Режимы внутри**: Информационный / Аналитический / Глубокий анализ — выбирается автоматически по типу вопроса.

---

### 2. CRITICAL ADVISOR 1.0.1 LITE
**Файл**: [critical_advisor_1.0.1_LITE.md](critical_advisor_1.0.1_LITE.md)  
**Токены**: ~1,480  
**Платформы**: Все, включая Ollama и модели с малым контекстом (< 8k)

**Для чего**: Облегчённая версия того же протокола. Подходит когда нужно:
- Быстро получить ответ с уровнем доверия
- Работать в ограниченном контексте
- Задавать информационные вопросы
- Использовать на слабых или локальных моделях

**Отличие от STANDARD**: Нет расширенной проверки ошибок (M1/M2), нет альтернативных взглядов (M3). Ядро протокола сохранено.

## 🚀 Как использовать

### Через Perplexity Space (рекомендуется)

В начале треда напиши:
> *"Загрузи репозиторий https://github.com/WHO-AM-I-52/prompts, прочитай README и предложи выбрать промт"*

ИИ загрузит этот файл, покажет описания и спросит какой применить.

### Вручную

1. Выбери версию по задаче (см. таблицу ниже)
2. Попроси ИИ загрузить конкретный файл из репозитория
3. Работай
