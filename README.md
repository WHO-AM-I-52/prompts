## Как использовать

### Вариант 1 — через Perplexity Space

В начале каждого треда попроси:
> "Загрузи промт из репозитория https://github.com/WHO-AM-I-52/prompts и спроси какой использовать"

### Вариант 2 — вручную

1. Выбери версию:
   - Контекст < 8k → LITE
   - Контекст ≥ 8k → STANDARD
2. Попроси ИИ загрузить конкретный файл
3. Работай

## Выбор версии

```
Контекст < 8k?    → LITE  (~1,480 токенов)
Контекст ≥ 8k?   → STANDARD (~6,420 токенов)
```
